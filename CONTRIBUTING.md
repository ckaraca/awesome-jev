# Contributing

Thanks for helping grow the list.

## Adding a project

1. It must use Jev (or TypeSafe's System One API) in a meaningful way, or be a clearly labeled open replication.
2. It must be public and have a README that explains what it does and how to run it.
3. Add it to the right section, at the end of that section.
4. Use this format: `- [owner/repo](https://github.com/owner/repo) - Short description ending with a period.`
5. Keep the description factual. If the project trades, spends money, or controls devices, say what the default safety mode is.
6. One project per pull request.

## Removing or fixing entries

Dead links, renamed repos, and archived projects can be fixed or removed in any PR. Note what changed in the description.
